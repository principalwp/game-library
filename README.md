# Game Collector

> An invite-only social game library powered by the [IGDB](https://www.igdb.com/)
> catalog — search games, track them by status, follow other collectors, and
> browse a shared activity feed.

A self-contained WordPress plugin. **Requires** WordPress 6.3+ and PHP 7.4+.

## Demo

A ~30-second silent walkthrough recorded against
[WordPress Playground](https://wordpress.github.io/wordpress-playground/). Game data
is pre-seeded for a self-contained demo; cover art is real imagery from IGDB's image CDN.

**▶ [`game-collector-sol-demo.webm`](game-collector-sol-demo.webm)**

What it covers:

- **My Library** — games organized by status (finished / playing / backlog / wishlist), with cover art.
- **Search & add** — search returns games with real IGDB cover art; adding one caches it locally and logs an activity event.
- **Community** — an invite-only member directory; follow a collector to track their activity.
- **Activity feed** — your own actions plus everyone you follow, newest first.
