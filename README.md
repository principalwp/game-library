# Game Collector

> An invite-only community for video-game collectors, powered by the
> [IGDB](https://www.igdb.com/) catalog — members search games, track their library
> (playing / finished / backlog / wishlist), follow each other, and browse an
> activity feed.

A self-contained WordPress plugin. **Requires** WordPress 6.0+ and PHP 7.4+.
Licensed **GPL-2.0-or-later**.

## Demo

A ~28-second silent walkthrough recorded against
[WordPress Playground](https://wordpress.github.io/wordpress-playground/). Game data
is pre-seeded for a self-contained demo; cover art is real imagery from IGDB's image CDN.

**▶ [`game-collector-fable-demo.webm`](game-collector-fable-demo.webm)**

![My Library — the member's landing page: cover art and per-game status](my-library.webp)

What it covers:

- **My Library** — your games and cover art at a glance; tabs filter the grid by status.
- **Search & add** — search hits IGDB and shows real cover art from images.igdb.com; adding a game caches it locally and logs an activity event.
- **Members & following** — browse another member's read-only library and follow them; the change persists immediately.
- **Activity feed** — your actions plus everyone you follow, newest first.
